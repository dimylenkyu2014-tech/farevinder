# ✈️ Fare Finder — Ryanair + Wizz Air → Telegram

Два раза в день (утром и вечером) проверяет все направления **Ryanair** и **Wizz Air** из **Варны (VAR), Софии (SOF), Бухареста (OTP), Бургаса (BOJ)** на 180 дней вперёд и пишет в Telegram, когда:

- 📉 **цена упала** (≥20% и ≥8 €);
- 🔥 **дёшево**: туда-обратно дешевле 60 €, в одну сторону дешевле 30 €;
- 🆕 **новое направление** или новый месяц продаж (туда-обратно < 80 €, в одну сторону < 45 €);
- ✈️ раз в день — **сводка**: ТОП-10 туда-обратно и ТОП-10 в одну сторону.

**Туда-обратно** — главный режим: бот подбирает самую дешёвую пару «туда + обратно» с поездкой на 2–10 ночей. Для Wizz Air можно вернуться в **другой** из 4 городов (например, туда из Варны, обратно в Софию, если так дешевле) — тогда в сообщении будут две ссылки: «туда» и «обратно». Ryanair — возврат в тот же аэропорт.

Цены — на 1 взрослого, без багажа, в EUR (RON и другие валюты пересчитываются по курсу ЕЦБ). Для каждой пары «маршрут × месяц вылета» отслеживается самый дешёвый вариант.

## Настройка (≈10 минут)

### 1. Telegram-бот
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя → получишь **токен** вида `123456:ABC...`.
2. Напиши своему новому боту любое сообщение (например, `/start`).
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": 123456789` — это твой **chat_id**.

### 2. Репозиторий на GitHub
1. Создай **публичный** (Public) репозиторий (например, `fare-finder`) и загрузи туда все файлы из этой папки (кнопка *Add file → Upload files*, папку `.github` тоже — она обязательна).
2. *Settings → Secrets and variables → Actions → New repository secret*, добавь два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHAT_ID` — твой chat_id.
3. *Settings → Actions → General → Workflow permissions* → **Read and write permissions** → Save (бот сохраняет историю цен в `state/fares.json`).

### 3. Запуск
*Actions → Fare Finder → Run workflow*:
- `test` — проверка: бот пришлёт «на связи»;
- `normal` — первая проверка: бот запомнит текущие цены (это база, алертов ещё не будет);
- `digest` — сразу прислать ТОП дешёвых.

Дальше всё работает само по расписанию.

## Как менять настройки
Редактируй `config.yaml` прямо на GitHub (иконка карандаша):

| Параметр | Что делает |
|---|---|
| `origins` | аэропорты вылета |
| `horizon_days` | сколько дней вперёд смотреть |
| `round_trip.min_nights` / `max_nights` | длина поездки |
| `round_trip.return_to_any_origin` | разрешить возврат в другой из 4 городов (Wizz) |
| `alerts.round_trip.max_price` | порог «дёшево» туда-обратно |
| `alerts.one_way.max_price` | порог «дёшево» в одну сторону |
| `alerts.one_way.enabled` | `false` — не слать алерты по билетам в одну сторону |
| `alerts.drop_pct` / `drop_abs` | насколько должна упасть цена |
| `digest.hour_utc` | когда слать ТОП (UTC; 6 = 8:00 по Киеву / Варне зимой) |
| `only_destinations` | следить только за этими (напр. `[LTN, STN, BGY]`) |
| `exclude_destinations` | исключить направления |
| `wizz_discount_club` | цены для членов WDC |

Частота — строка `cron` в `.github/workflows/fares.yml`.

## Важно знать
- **Это неофициальные API.** Ryanair Fare Finder обычно работает стабильно. Wizz Air защищается от ботов и иногда режет запросы с серверов GitHub (ошибка 429/403). Бот это переживает: Ryanair продолжит работать, а в сводке появится «⚠️ Ошибок при сборе». Если Wizz блокируется постоянно — увеличь `wizz_request_delay` до 2–3 или запускай бот у себя на компьютере (см. ниже).
- Один полный прогон по Wizz на 180 дней ≈ 30–45 минут (сотни маршрутов × 7 периодов по 30 дней; обратные рейсы идут в том же запросе). Можно ускорить, сузив `only_destinations` или `horizon_days`.
- **Почему публичный репозиторий:** для публичных репозиториев минуты GitHub Actions бесплатны и без лимита (у приватного — 2000 мин/мес, а нужно ~2400). Токен и chat_id хранятся в секретах и **не видны** никому. Видны только код и история цен в `state/fares.json`. Если захочешь приватный — поставь в `fares.yml` cron `0 6 * * *` (раз в день).
- GitHub может отключить расписание, если в репозитории 60 дней не было активности. Бот каждый раз коммитит `state/fares.json`, так что обычно этого не происходит.

## Запуск локально (по желанию)
```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=...  TELEGRAM_CHAT_ID=...
python -m bot.main --test      # проверка связи
python -m bot.main --dry-run   # вывести в консоль, ничего не отправлять
python -m bot.main             # обычная проверка
```
